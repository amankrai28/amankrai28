### What I've built (i.e. passion projects)

- **[Residual](https://github.com/amankrai28/residual-scanner)** - a real-estate mispricing scanner: a hedonic price model learns what every home *should* be worth from 5,000+ real sales, then flags the ones trading below fundamentals on streets where renovation permits are accelerating. [Live demo](https://amankrai28.github.io/residual-scanner/).
- **[Be the Shark](https://github.com/amankrai28/be-the-shark)** - 🦈 Shark Tank India deal simulator — read a real anonymized pitch, make your call, get scored against what actually happened.
